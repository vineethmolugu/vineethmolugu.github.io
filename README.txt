VINEETH PORTFOLIO — GITHUB PAGES SETUP

1. In index.html replace:
   YOUR_EMAIL_HERE with your email address
   YOUR_LINKEDIN_URL_HERE with your full LinkedIn profile URL

2. On GitHub create a PUBLIC repository named exactly:
   vineethmolugu.github.io

3. Upload these three files to the repository root:
   index.html
   style.css
   script.js

4. Open repository Settings > Pages.
   Under Build and deployment choose Deploy from a branch.
   Select branch: main and folder: / (root), then Save.

5. After GitHub publishes the site, visit:
   https://vineethmolugu.github.io/

Important: The site intentionally does not include a resume download yet because no resume file was supplied in this step. Add your PDF later and link it from the page if desired.
